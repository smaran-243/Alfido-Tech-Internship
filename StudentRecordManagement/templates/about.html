About The Project

College Submission and Viva Presentation Project

Project Objective

The primary objective of this project is to develop a fully functional, lightweight **Student Record Management System** to demonstrate fundamental backend web development and database operations. It serves as a practical implementation of core CRUD (Create, Read, Update, Delete) concepts inside a clean web architecture, highlighting routing parameters, database persistence, layout templates, and HTML form handling.

Technologies Used

  • Python 3: The primary language for application logic.
  • Flask: A lightweight WSGI web application micro-framework.
  • Flask-SQLAlchemy: An extension that adds SQLAlchemy support for interacting with SQLite databases using Object Relational Mapping (ORM).
  • SQLite: A self-contained, serverless SQL database engine.
  • Bootstrap 5 & CSS: Used to design responsive, mobile-friendly interfaces.
  • Jinja2: A template engine for rendering dynamic HTML content on the server.

Features

  • Complete Database CRUD operations.
  • Full Search filters (Name, Department, Roll No).
  • Sorting controls by Name or Department.
  • Dynamic Flask Flash messages for user alerts.
  • Safe confirmation pages prior to record deletes.
  • Responsive fluid grid layout (works on desktop/mobile).

Scope & Future Enhancements

Currently, the scope of this project is to serve as an academic submission demonstrating Flask backend and SQLite crud operations. It allows basic student administrative tracking.

Future extensions include: Implementing student/admin user authentication, exporting database records to CSV/PDF sheets, adding course registration, tracking fee statuses, and adding interactive charts to display GPA trends.
